# Subir a GitHub

Sube el contenido de esta carpeta a la raíz del repositorio.

La estructura final debe ser:

- `.github/workflows/build-apk.yml`
- `ChileTV_IPTV_Android_TV13_repo/ChileTV_IPTV_Android/...`

Al hacer commit en `main`, GitHub Actions compilará automáticamente el APK.
El artefacto se llama `ChileTV-IPTV-MX10-LEGACY-v5`.
